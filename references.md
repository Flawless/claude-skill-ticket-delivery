# References

The skill's documents borrow names and structure from these standards. It does not claim conformance.
The full texts are paywalled and were not read; what is used here comes from the publishers' scope pages,
public previews and secondary summaries. Editions and statuses checked 2026-11-06.

| Standard | Status | Shaped |
|---|---|---|
| [ISO/IEC/IEEE 29119-3:2021](https://www.iso.org/standard/79429.html), Software testing — Part 3: Test documentation | current, edition 2; replaced the 2013 edition, which replaced IEEE 829 | test plan, test case specification, test log (gate), test execution log and status report (test report), test completion report (run record) |
| [ISO/IEC/IEEE 29148:2018](https://www.iso.org/standard/72089.html), Requirements engineering | current; edition 3 in draft as [ISO/IEC/IEEE DIS 29148](https://www.iso.org/standard/94091.html) | traceability matrix: requirement (criterion or quality requirement) → test case → result |
| [ISO/IEC 25010:2023](https://www.iso.org/standard/78176.html), SQuaRE — Product quality model | current, edition 2; nine characteristics | the checklist the test designer walks to derive quality requirements |
| [ISO/IEC 25023:2016](https://www.iso.org/standard/35747.html), SQuaRE — Measurement of product quality | current; a successor (ISO/IEC 25000-23) in development | how quality requirements are expressed as metric + threshold |
| [IEEE 1016-2009](https://standards.ieee.org/ieee/1016/4502/), Software design descriptions | inactive-reserved since 2020-03-05 | design specification |
| [IEEE 1028-2008](https://standards.ieee.org/ieee/1028/4402/), Software reviews and audits | inactive-reserved since 2019-11-07 | review report: findings, dispositions, verification |

Inactive-reserved means IEEE no longer maintains the standard; it is cited here for its document shape, not
as a current requirement.
